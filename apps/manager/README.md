# Manager App

Manager application for the Shiftly ERP system.

## Features

- Team Management
- Project Management
- Reports & Analytics
- Approvals (Leave, Expenses, Time-off)

## Development

```bash
# From root directory
pnpm dev:manager

# Or from this directory
pnpm dev
```

The app runs on port 3003.

## Build

```bash
pnpm build:manager
```
